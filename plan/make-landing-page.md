Ashiartのすばらしさが最大限伝わるような，ランディングページを作成してください．

現在フロントエンドのトップページは現状使われておらず自動的に/homeにダイレクトされるようになっていますが，このページを，アプリのカラーやデザインに合ったランディングページにしてください．

ページでは，アプリの使い方や魅力についても様々解説したいです． @README.md などを参考に沢山の情報を含めてください．また，ボタンのプライマリカラーは緑系統にしてください．

アプリ自体はスマートフォン前提ですが，ランディングページはレスポンシブに作成してください．
アプリで使われている画像などのアセットも適宜用いていいです．

アプリの動作確認は，http://localhost:3000 で行うことができます．
アクセスできない場合は，以下の手順で起動してください：

```zsh
cd frontend
npm run dev
```

ページを作成したらAntigravity Browser Extensionを用いてデザインと画面遷移の確認を行ってください．確認した内容は記録してください．
